# Диагностика MultiAI — 28.10.2026

## Установлено

Endpoint https://multiai.store/v1 отвечает на GET /models HTTP 200; deepseek-v4.1-flash и gpt-5.6-luna присутствуют в авторизованном каталоге. Текущий ключ принимается для реальных генераций. Ошибок 401/429/5xx в этих сетевых пробах не наблюдалось; их поведение проверяется детерминированными HTTP-тестами.

DeepSeek: простой запрос без инструментов ReadTimeout за 40.61 с; JSON пришёл за 27.55 с, повторный прямой JSON за 41.05 с; native tool call ReadTimeout за 40.61 с. Это доказывает нестабильную задержку на текущем маршруте, но не позволяет определить внутренний сбой провайдера или считать модель постоянно недоступной. Два последовательных вызова в агенте дополнительно не помещались в общий лимит 35 с.

Проверена gpt-5.6-luna внутри того же MultiAI, без смены провайдера/ключа. Повторяемый probe: простой ответ 2.66 с, JSON 8.48 с, json_schema strict 9.77 с, native single tool 9.50 с — HTTP 200, ожидаемый формат во всех четырёх случаях. Артефакт artifacts/provider-probe.json. Строгая схема проверена минимальной пробой; это не обещание поддержки любых схем. Производственное приложение сохраняет json_object плюс собственную доменную валидацию. Native tool calling проверен, но исполнение бизнес-инструментов идёт через ограниченный Decision-протокол. Неожиданные native calls, включая несколько вызовов, не выполняются.

## Изменения

Локальная .env использует gpt-5.6-luna; ключ не менялся. Для явных explain/compare/details/prioritize исключён повторный выбор уже известного инструмента моделью: один вызов выбирает проверенные основания. Исследование альтернатив сохраняет планирование. Общий дедлайн 35 с, не более двух попыток на стадию, отсутствие повторов ошибок ключа/баланса и ограниченный Retry-After сохранены. Не увеличивали таймауты бесконечно.

Общий парсер completion отвергает length/content_filter/tool_calls, несколько choices, неожиданные native calls и отказ модели, даже когда content выглядит валидным JSON. Полезный JSON не считается завершённым ответом при сигнале усечения. Добавлены девять регрессионных случаев и тест одного вызова для явного сравнения.

## Безопасность и запуск

Текущий ключ не найден ни в неигнорируемых файлах, ни во всех доступных Git-объектах истории. Это не доказывает отсутствие любых прежних отозванных ключей, значения которых неизвестны. .env исключён из Git; необработанные ответы и заголовки в отчёты не записываются.

Docker отсутствует; Compose/PostgreSQL исполнением не проверены. Dockerfile статически сохраняет multi-stage, pinned image/dependencies, nonroot; Compose — PostgreSQL, healthchecks, depends_on и 8080. Команды для Windows: docs/windows-docker-check.md. До сдачи нужны реальный Docker-прогон, публичный скринкаст и официальный репозиторий. Push/submission tag не выполнялись.
