# MultiAI: локальное подключение O!RIVANE

Приложение использует OpenAI-compatible Chat Completions: `https://multiai.store/v1/chat/completions`.
Инструкции проверены в кабинете MultiAI 27 октября 2026: разделы «API-доступ» и «Документация → Подключение IDE / CLI».

1. Создайте отдельный обычный ключ `ma-live-…`, выбрав «Обычный (без роли)». Дополнительная роль провайдера добавляет инструкции к каждому запросу и может конфликтовать со схемой приложения. Управляющий ключ `ma-mgmt-…` не нужен.
2. Задайте лимит расходов ключа. Это лимит биллинговых единиц MultiAI, а не обещанное число запросов или сырых токенов модели.
3. Сохраните ключ только в локальном `.env` как `LLM_API_KEY`. Файл исключён из Git. Не заменяйте `.env` целиком при смене модели.
4. Укажите `LLM_BASE_URL=https://multiai.store/v1` и модель из актуального `/v1/models`. Идентификаторы с `ma-` предназначены для Cursor и здесь не используются.
5. После изменения окружения перезапустите backend. Для Docker: `docker compose up --build -d`. Для прямого запуска: `python -m uvicorn app.main:app --host 127.0.0.1 --port 8080` из активного окружения проекта.
6. Проверьте реальный вызов командой `python scripts/check_llm.py`. `/health` проверяет приложение, а не доступность AI.

Скрипты подключения IDE из кабинета для O!RIVANE не требуются: они изменяют конфигурацию инструмента разработки, а не этого backend. Для работы облачной модели нужны интернет и доступный баланс. При ошибке провайдера приложение сообщает о переходе на ограниченный локальный интерпретатор правил.

## Сравнение моделей

Результаты первого реального сравнения и обоснование выбора: [отчёт](multiai-model-comparison.md).

Тесты платные, используют только синтетические запросы, не создают заказов и не публикуют ключ. Они разделяют понимание самой модели и результат обработки в приложении.

```powershell
python scripts/compare_llm_direct.py --models gpt-6.1-terra gemini-3.8-flash deepseek-v4.1-flash --output artifacts/multiai-direct-comparison.json
python scripts/compare_llm.py --models gpt-6.1-terra gemini-3.8-flash deepseek-v4.1-flash --suite informal --output artifacts/multiai-informal-comparison.json
python scripts/compare_llm.py --models gpt-6.1-terra gemini-3.8-flash deepseek-v4.1-flash --suite core --output artifacts/multiai-core-comparison.json
```

Один проход малого авторского набора не доказывает общее превосходство модели. Успешные локальные проверки без обращения к API не считаются успехами модели. `usage` провайдера сохраняется без пересчёта неизвестных единиц в рубли. Исторические результаты Polza не перезаписываются.
