# Открытые данные поездки

Read-only endpoint: `GET /api/sessions/{id}/destination-context?revision=N`; раздел «Ближе к месту поездки». Загружается после результатов, вне LLM deadline. Версия проверяется до и после получения данных. Источники получают только города/координаты/диапазоны дат, без ключа MultiAI, чата, контактов и заказа. Отели/транспортные цены демокаталога не меняются.

## Подключения

- Open-Meteo / GeoNames: координаты городов; для российского демокаталога при неоднозначности предпочитается RU. Координаты относятся к городу, не отелю.
- Open-Meteo forecast: текущая модельная погода и прогноз до 16 дней. Только пересечение с датами поездки; частичное покрытие явно обозначено.
- Open-Meteo archive: для дальних дат средние дневные максимумы/ночные минимумы того же месяца предыдущего календарного года. История, не прогноз и не климатическая норма; период указан.
- OpenStreetMap: карта по внешней ссылке и iframe по нажатию, с предупреждением о передаче IP. До нажатия карта не загружается. Видимая атрибуция ODbL.
- OSRM: автомобильные километры/часы, ссылка на маршрут. Без пробок, остановок и проверки ограничений. Это не время перелёта или поезда.
- Overpass / OpenStreetMap: достопримечательности/музеи/смотровые точки в 12 км, вокзалы/аэропорты в 30 км. Ссылки из проверенных type/id. Неполный ответ с remark отвергается; часы работы/доступность/цены посещения не подтверждаются.

Пользователь подтвердил отсутствие транспортного ключа. Живые цены/наличие билетов и расписания не подключены; демонстрационные цены явно подписаны. Внешние сведения не становятся непроверенными фактами существующего evidence-протокола агента.

## Условия и надёжность

Бесплатный Open-Meteo предназначен для некоммерческого использования, без SLA; коммерческому запуску потребуется соответствующий доступ. Данные CC BY 4.0 с видимым источником. Публичные OSRM/Overpass также не гарантируют доступность.

Документация: [прогноз](https://open-meteo.com/en/docs), [геокодирование](https://open-meteo.com/en/docs/geocoding-api), [условия](https://open-meteo.com/en/pricing), [OSRM](https://project-osrm.org/docs/v5.24.0/api/), [карты OSM](https://operations.osmfoundation.org/policies/tiles/).

Кэш: города/история 24ч, погода 15мин, места/дорога 6ч, ошибки 30с; 256 ключей, 4 параллельные загрузки. Запросы одного ключа объединяются. Внешний вызов до 6с, задача источника до 7с, endpoint до 10с. Компоненты независимы, отказ одного сохраняет остальные. Shutdown отменяет задачи. Кэш хранится в памяти процесса.

## Реальные проверки

28.10.2026, через HTTP приложения: Сочи через 3 дня — 1,187с, геокодирование/погода/дорога успешно; через 55 дней — 0,297с с кэшем, история успешно, чужой прогноз не подставлен. Артефакт `artifacts/destination-context-live.json`.

**Overpass не подтвердил живой ответ:** отказы/таймауты в текущем маршруте. Wikipedia возвращала 403. Реальные достопримечательности/станции в этом прогоне не загружены; интерфейс сообщает об отказе, карта доступна. Парсер мест проверен тестами, это не облачный успех. Редактирующий OSM API диагностически исследован, но в приложение не встроен: он не предназначен для этого read-only сервиса.

UI 1440/390/320: реальные прогноз/дорога, карточки поиска, карта по нажатию, без переполнения/ошибок браузера; скриншоты `artifacts/destination-ui/`. Регрессии проверяют частичные/дальние даты, null, отказ источника, кэш, ссылки, revision и отсутствие мутаций. Расчётный маршрут не подтверждает доступность дороги на дату поездки.

Финальные проверки: 491 Python-тест и 28 JavaScript-тестов прошли; Ruff и whitespace diff прошли. Сохранилось прежнее предупреждение Starlette/httpx TestClient. HTML endpoint iframe OpenStreetMap отдельно вернул HTTP200; это не нагрузочная проверка сервиса тайлов. Локальный просмотр запущен на http://127.0.0.1:8082 в local-режиме: публичные сведения реальные, подбор каталога локальный. В проверенных новых исходниках/артефактах текущий ключ не найден.
