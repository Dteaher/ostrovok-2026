# O!RIVANE — визуальное обновление

Цель: приблизить реальный интерфейс к предоставленному premium travel-референсу, сохранив FastAPI, API, типизированные условия, сравнение, пересборку и демооформление.

- [x] Фотографические локальные изображения и локальная типографика с источниками/лицензиями.
- [x] Шапка O!RIVANE, фотографический hero, действующая строка запроса, четыре тематических примера, шесть районов существующего каталога, четыре этапа сценария.
- [x] Общие цветовые/типографические tokens, единый стиль результатов, плана и оформления; без нового фреймворка.
- [x] «Мои поездки» возвращает действительно сохранённые в этом браузере сессии через существующий API; без выдуманного аккаунта или поддержки.
- [x] Браузерная проверка 1440/768/390, клавиатура, изображения, ошибки и весь путь до демозаказа; существующие backend-тесты и health.

Решение: районы Большого Сочи вместо недоступных зарубежных направлений. Честная маркировка демонстрационного каталога и фотографий, которые не являются фото вымышленных отелей. GitHub, Docker и backend-поведение не меняются. Подтверждение плана не требуется: пользователь прямо поручил самостоятельную реализацию после анализа.

Фактическая проверка: 128 backend-тестов, прежний browser acceptance и новый `tests/rivane_verify.py`. Просмотрены desktop/tablet/mobile, результаты, оформление, сохранённые поездки. Независимый review нашёл перенос контактных данных/согласия между разными поездками и два дефекта фокуса/подписи меню: исправлены, воспроизведения независимо перепроверены. Дополнительно исправлена гонка закрытия диалога с запоздавшим GET. Скринкаст обновлён.
