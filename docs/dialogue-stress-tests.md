# Расширенная проверка диалога, 28 октября 2026

Добавлен независимый авторский набор: **33 сценария, 38 шагов**. Ожидания зафиксированы до вызова API и не менялись под ответы модели. Позже проверки усилены: однозначное изменение не должно оставлять лишних уточнений, а посторонний запрос — создавать заказ, менять выбранный отель или добавлять уточнения к поездке.

## Покрытие

- Суммы с пробелами, десятичной дробью и словами; рейтинг и расстояние до пляжа.
- Кошка, доступность, смена транспорта, самостоятельная дорога, трое взрослых, двое детей.
- Обязательное, желательное и снятое требование; неподдерживаемые характеристики.
- Абсолютная дата и относительный перенос; повтор одинакового запроса.
- Сравнения без изменения поездки; противоречия; ответ на возраст ребёнка местоимением.
- Последовательность «изменить бюджет → добавить питомца → сократить поездку → снять завтрак» с сохранением всех остальных условий.
- Семь посторонних/провокационных запросов: умножение, стих, программирование, рецепт завтрака с ценой, выбор ноутбука, попытка получить ключ и оформить покупку, покупка телефона.

## Результат

| Проверка | Итог |
|---|---:|
| Окончательный прогон через MultiAI / DeepSeek | **38/38** |
| Посторонние и провокационные запросы в этом прогоне | **7/7** |
| Автономные тесты проекта | **324 прошли** |
| Ruff | прошёл |

В финальном прогоне 27 запросов API вернули HTTP 200; 26 ответов приняты как извлечение LLM, один обработан запасным локальным режимом. Ещё 11 шагов выполнены без API. Поэтому 38/38 означает корректные исходы приложения, а не 38 успехов самой модели.

Режим без ключа: 37/38. Сумма «двести сорок тысяч» словами не извлечена локальным интерпретатором; через AI этот случай проходит. Локальные правила остаются ограниченным запасным режимом.

После перезапуска приложения проверен настоящий HTTP-путь: создание и выбор поездки → рецепт и покупка телефона без изменения условий и без заказа → сравнение без применения → пересборка с сохранением отеля и бюджета → демонстрационное оформление и идемпотентный повтор. Проверки прошли. Реальных платежей и поставщиков в этом сценарии нет.

## Что нашли и исправили

Первый реальный прогон дал 33/38, а автономный — 29/38. Повторы с более строгими проверками выявили дополнительные варианты поведения модели; промежуточные результаты сохранены, не перезаписаны.

- Обычные слова после «на» ошибочно считались направлением, блокируя AI и оставляя лишние уточнения. Для проверенных денежных и связанных с доступностью выражений это исправлено.
- «Вид из номера» превращался в город отправления «Номер». Убрано такое распознавание.
- «Ему 8 лет» не завершало уточнение о втором ребёнке. Контекстное местоимение теперь разбирается только при ожидаемом ответе о возрасте; первый ребёнок сохраняется.
- Посторонняя цена могла стать бюджетом поездки, а рецепт за 500 рублей — вызвать ошибку валидации. Явные рецепты и покупки техники отсеиваются до извлечения денежных и других условий.
- «В Тбилиси вместо Сочи» могло вернуть Сочи. Старое направление после «вместо» больше не выбирается.
- Пустой ответ или лишнее уточнение модели на «добавь кошку» теряли известную команду и загрязняли следующие шаги. Полные однозначные команды добавления питомца обрабатываются локально, до вызова модели.
- Ответ `unknown` мог стереть локально обнаруженные неподтверждённые обязательные требования. Метаданные ограничений каталога теперь сохраняются и в этом случае.

Каждая найденная причина закреплена автономным регрессионным тестом. Исправления касаются `app/parser.py` и контекстного ответа в `app/service.py`; расчёт цен и поиск не менялись.

## Повторить

Реальный прогон платный, использует синтетические тексты и не создаёт заказов:

```powershell
python scripts/compare_llm.py --models deepseek-v4.1-flash --suite stress --output artifacts/stress-new-run.json
python scripts/compare_llm.py --rules-only --suite stress --output artifacts/stress-offline-new-run.json
python -m pytest -q
python -m ruff check app scripts tests
```

Набор: `scripts/dialogue_stress_cases.py`. Проверки набора: `tests/test_dialogue_stress.py`; найденные границы: `tests/test_dialogue_boundaries.py`, `tests/test_assistant_intent.py`.

Финальные локальные результаты: `artifacts/stress-deepseek-final-checked.json`, `artifacts/stress-offline-final.json`, `artifacts/backend-intent-http.json`. Ключи в отчётах отсутствуют; `.env` исключён из Git.

Это функциональная проверка ограниченного набора на одной основной модели. Она не доказывает понимание любых перефразировок, защиту от всех инъекций или стабильность провайдера под нагрузкой. В частности, локальный фильтр посторонних задач конечен; для дальнейшего повышения уверенности нужны новые независимые формулировки и повторные прогоны во времени. Старое предупреждение Starlette TestClient/httpx сохраняется; Docker не проверялся в этой среде.
